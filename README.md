# 자동차 경주

## 프로젝트 소개

여러 대의 자동차가 주어진 횟수 동안 전진하거나 멈추는 자동차 경주 게임을 구현한다.

각 자동차는 무작위 값에 따라 전진하며, 경주가 끝나면 가장 멀리 이동한 자동차를 우승자로 출력한다.

## 기능 목록

### 자동차 이름 입력

* [ ] 경주에 참여할 자동차 이름을 입력받는다.
* [ ] 입력받은 자동차 이름을 쉼표(`,`) 기준으로 구분한다.
* [ ] 입력받은 이름으로 자동차를 생성한다.

### 시도 횟수 입력

* [ ] 자동차가 이동을 시도할 횟수를 입력받는다.
* [ ] 입력받은 문자열을 숫자로 변환한다.

### 자동차 이동

* [ ] 각 자동차에 대해 `0`부터 `9` 사이의 무작위 값을 생성한다.
* [ ] 생성된 값이 `4` 이상이면 자동차가 한 칸 전진한다.
* [ ] 생성된 값이 `4` 미만이면 자동차가 멈춘다.
* [ ] 모든 자동차가 한 번씩 이동을 시도하면 한 라운드가 끝난다.
* [ ] 입력받은 시도 횟수만큼 경주를 반복한다.

### 실행 결과 출력

* [ ] 경주 시작 전에 실행 결과 안내 문구를 출력한다.
* [ ] 각 라운드가 끝날 때마다 자동차별 이동 결과를 출력한다.
* [ ] 자동차의 위치를 하이픈(`-`)으로 표현한다.
* [ ] 자동차 이름과 이동 위치를 함께 출력한다.

### 우승자 선정

* [ ] 자동차 중 가장 멀리 이동한 위치를 구한다.
* [ ] 가장 멀리 이동한 자동차를 우승자로 선정한다.
* [ ] 같은 위치의 자동차가 여러 대라면 공동 우승자로 선정한다.
* [ ] 공동 우승자는 쉼표와 공백(`, `)으로 구분하여 출력한다.

## 예외 처리

### 공식 요구사항

* [ ] 자동차 이름이 5자를 초과하면 `IllegalArgumentException`을 발생시킨다.
* [ ] 잘못된 값을 입력하면 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 직접 결정할 예외 정책

기능 요구사항에 명시되지 않은 다음 입력의 처리 기준은 구현 전에 직접 결정한다.

* [ ] 자동차 이름이 비어 있는 경우
* [ ] 자동차 이름이 공백으로만 이루어진 경우
* [ ] 자동차 이름이 중복된 경우
* [ ] 쉼표 앞뒤에 공백이 포함된 경우
* [ ] 시도 횟수가 숫자가 아닌 경우
* [ ] 시도 횟수가 `0` 이하인 경우
* [ ] 자동차 이름 입력의 처음이나 마지막에 쉼표가 있는 경우

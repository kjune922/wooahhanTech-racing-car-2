# 자동차 경주

## 프로젝트 소개

여러 대의 자동차가 주어진 횟수 동안 전진하거나 멈추는 자동차 경주 게임을 구현한다.

각 자동차는 무작위 값에 따라 전진하며, 경주가 끝나면 가장 멀리 이동한 자동차를 우승자로 출력한다.

## 기능 목록

### 자동차 이름 입력

* [x] 경주에 참여할 자동차 이름을 입력받는다.
* [x] 입력받은 자동차 이름을 쉼표(`,`) 기준으로 구분한다.
* [x] 입력받은 이름으로 자동차를 생성한다.

### 시도 횟수 입력

* [x] 자동차가 이동을 시도할 횟수를 입력받는다.
* [x] 입력받은 문자열을 숫자로 변환한다.

### 자동차 이동

* [x] 각 자동차에 대해 `0`부터 `9` 사이의 무작위 값을 생성한다.
* [x] 생성된 값이 `4` 이상이면 자동차가 한 칸 전진한다.
* [x] 생성된 값이 `4` 미만이면 자동차가 멈춘다.
* [x] 모든 자동차가 한 번씩 이동을 시도하면 한 라운드가 끝난다.
* [x] 입력받은 시도 횟수만큼 경주를 반복한다.

### 실행 결과 출력

* [x] 경주 시작 전에 실행 결과 안내 문구를 출력한다.
* [x] 각 라운드가 끝날 때마다 자동차별 이동 결과를 출력한다.
* [x] 자동차의 위치를 하이픈(`-`)으로 표현한다.
* [x] 자동차 이름과 이동 위치를 함께 출력한다.

### 우승자 선정

* [x] 자동차 중 가장 멀리 이동한 위치를 구한다.
* [x] 가장 멀리 이동한 자동차를 우승자로 선정한다.
* [x] 같은 위치의 자동차가 여러 대라면 공동 우승자로 선정한다.
* [x] 공동 우승자는 쉼표와 공백(`, `)으로 구분하여 출력한다.

## 예외 처리

## 오늘 진행한 작업

- 자동차 이동 조건의 경계값 테스트를 작성했다.
    - 난수가 `3`이면 정지
    - 난수가 `4`이면 전진
- 자동차 이름 검증 테스트를 작성했다.
    - 빈 문자열, 공백, `null`
    - 5자까지 허용하고 6자부터 예외
    - 자동차 이름 중복 예외
- 시도 횟수 검증 테스트를 작성했다.
    - `0`과 음수는 예외
    - `1`은 정상 처리
    - 숫자가 아닌 입력은 예외
- 단위 테스트와 전체 애플리케이션 테스트를 실행했다.

## 배운 점

경계값 테스트에서는 조건과 멀리 떨어진 임의의 값을 사용하는 것보다
경계의 바로 양쪽 값을 사용하는 것이 중요하다는 것을 배웠다.

자동차 이름이 5자 이하라는 조건은 정확히 5자와 6자를 테스트했고,
자동차가 4 이상일 때 이동한다는 조건은 3과 4를 테스트했다.

## 어려웠던 점

추가로 어려운걸 주석으로 각 테스트문구에 설명처럼 넣었다.

테스트가 통과하면 의도한 기능이 검증됐다고 생각했지만,
`runException()`에 입력 문자열을 각각 전달하면서 실제 입력 순서를 잘못 이해했다.

자동차 여러 대의 이름은 `"lee,kim"`처럼 하나의 입력 문자열로 전달해야 하는데,
`"lee", "kim"`으로 전달하면 `"kim"`이 시도 횟수로 사용된다.

## 문제를 해결한 과정

`Console.readLine()`이 호출될 때마다 `runException()`의 인자가
순서대로 하나씩 사용된다는 것을 확인했다.

이에 따라 자동차 이름은 쉼표로 연결한 하나의 문자열로 전달하고,
두 번째 인자에 시도 횟수를 전달하도록 테스트를 수정했다.

테스트가 통과하는지만 보는 것이 아니라,
정말 예상한 코드와 입력 때문에 통과했는지 확인해야 한다는 점을 배웠다.
